Справка

Видна только после входа в программу

Вход и пароль

  • Вход только по паролю, без логина. Пароль — не короче {{ min_password }} символов; раз он единственный, сделайте его длинным.
  • После {{ max_attempts }} неверных паролей подряд вход с этого устройства блокируется на {{ lockout_minutes }} минут.
  • Сменить пароль: ссылка «Сменить пароль» внизу меню. После смены все устройства должны войти заново.
  • Если забыли пароль: на компьютере с программой закройте её окно и запустите в папке программы start.bat --set-password (на Linux / macOS — ./start.sh --set-password). Программа попросит ввести новый пароль дважды. Данные не меняются.

Запуск и доступ с других устройств

  • Программа работает, пока открыто окно start.bat. Чтобы она запускалась сама, положите ярлык на start.bat в автозагрузку (Win + R → shell:startup).
  • В сети сервиса откройте адрес, который показывает окно запуска (вида http://192.168.…:8000). Если не открывается — разрешите программе доступ в брандмауэре Windows. Компьютеру с программой лучше закрепить постоянный IP в настройках роутера.
  • Из дома: не открывайте порт программы в интернет через роутер. Проще всего — Tailscale: установите его на компьютер с программой и на свой телефон / домашний компьютер под одной учётной записью и открывайте http://<имя-компьютера>:8000.
  • Если нужен адрес в интернете с HTTPS (Cloudflare Tunnel, обратный прокси) — запускайте программу с переменной окружения DIESEL_HTTPS=1.
  • Параметры запуска: --port 8080 — другой порт; --host 127.0.0.1 — только с этого компьютера; --set-password — новый пароль.

Где хранятся данные и резервные копии

  • Все данные — в одном файле: {{ db_path }}. Рядом лежит secret_key — ключ сессий; если его потерять, просто придётся войти заново.
  • Скачать копию базы: Настройки → «Скачать копию базы». Можно прямо во время работы.
  • Делайте копию хотя бы раз в неделю и храните её не на том же компьютере (флешка, облако).
  • Восстановление: закройте программу, переименуйте скачанный файл в {{ db_path.name }} и положите в папку {{ data_dir }} вместо старого.
  • Папку с данными можно перенести переменной окружения DIESEL_DATA_DIR.

Как работают расчёты

Нумерация заказ-нарядов

  • Каждый год нумерация начинается с № 1. Номер удалённого заказ-наряда повторно не выдаётся.
  • 1 января заказ-наряды прошлого года уходят в «Архив заказ-нарядов», номер там показывается с годом: 15/2025.
  • Незакрытые заказ-наряды прошлого года остаются в общем списке, пока их не выдадут. Долги прошлых лет видны по фильтру «Оплата → Долг».

Долг

Заказ-наряд в статусе «Выдан», оплаченный не полностью. Заказ-наряды в работе с неполной оплатой — «не оплачен» / «аванс», в долги не входят.

Зарплата мастеров

  • У каждой услуги в прайсе задан процент мастеру. При добавлении работы в заказ-наряд цена и процент копируются из прайса; потом их можно поправить в строке. Изменение прайса не меняет старые заказ-наряды.
  • Работы попадают в зарплату, когда заказ-наряд переводят в «Готов» или «Выдан».
  • «К выплате» = всё начисленное − все выплаты (выплаты записываются в разделе «Зарплата» или расходом с указанием мастера).

Цена продажи на складе

  • Цена продажи = цена закупки × (1 + наценка). От 100 ₽ — всегда вверх до {{ price_step }} ₽ (120 → 150, 151 → 200); дешевле 100 ₽ — без округления.
  • Без наценки цену продажи задают вручную.
  • Если при приходе закупка подорожала, в карточке обновляется цена закупки и поднимается цена продажи: по наценке, а без наценки — с той же разницей между закупкой и продажей. Если закупка подешевела или не изменилась, карточка не меняется и цена продажи не снижается. Это можно отключить галочкой на странице прихода.
  • Приход и расход на складе считаются за выбранный период, остаток — на конец периода.

Поиск

Без учёта регистра («камаз» найдёт «КАМАЗ»), по телефону — по цифрам в любом формате, по артикулу — без учёта пробелов и дефисов.
