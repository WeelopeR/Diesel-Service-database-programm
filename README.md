# Дизель Сервис

Программа учёта для сервиса по ремонту дизельной топливной аппаратуры. Работает в браузере.

## Возможности

- **Заказ-наряды** — приём техники, работы и запчасти, статусы, оплаты, печатная форма, архив прошлых лет.
- **Клиенты** — карточки клиентов и их техники, история обращений.
- **Услуги** — прайс-лист.
- **Склад** — запчасти по типам, приход, расход и остатки.
- **Доходы и расходы** — учёт операций и отчёты.
- **Зарплата мастеров.**

## Установка (Windows)

1. Установите [Python](https://www.python.org/downloads/) 3.10 или новее. При установке отметьте «Add Python to PATH».
2. Скачайте программу (**Code → Download ZIP**) и распакуйте в любую папку.
3. Запустите `start.bat`. При первом запуске он сам установит нужные компоненты (нужен интернет).
4. Откройте в браузере адрес, который покажет окно программы.

Подробная инструкция по работе и настройке — в самой программе, раздел **«Справка»** (доступен после входа).
