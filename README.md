# Программа учёта дизельного сервиса

Веб-приложение для сервиса по ремонту дизельной топливной аппаратуры. Работает в браузере: с компьютера, на котором запущено, с других компьютеров и телефонов в сети сервиса, а при настройке — и из дома.

## Что умеет

| Раздел | Возможности |
|---|---|
| **Заказ-наряды** | Приём техники (неисправность, принятые агрегаты с номерами форсунок/ТНВД), работы из прайса, запчасти со склада, назначение мастеров, статусы *Принят → Диагностика → В работе → Ждёт запчасти → Готов → Выдан*, оплаты (в т. ч. частичные), печатная форма / PDF |
| **Клиенты** | Физлица и организации, несколько единиц техники у клиента (марка, модель, VIN, госномер, двигатель, топливная аппаратура), история обращений и долги |
| **Услуги** | Прайс-лист по категориям: у каждой услуги своя цена и **процент мастеру** |
| **Склад** | Остатки, приход от поставщика (несколько позиций одним документом), списание, инвентаризация, история движения, предупреждение о минимальном остатке. Запчасти из заказ-наряда **списываются автоматически**, при удалении строки или отмене заказ-наряда — возвращаются |
| **Доходы и расходы** | Все денежные операции по статьям, по способам оплаты (наличные / карта / безнал), прибыль за период, отчёт по месяцам. Оплаты заказ-нарядов, закупки на складе и выплаты зарплаты попадают сюда сами |
| **Зарплата** | Начисление мастерам = сумма их работ × процент из прайса. Выплаты и авансы, остаток к выплате |
| **Сотрудники** | Учётные записи и права доступа |
| **Настройки** | Реквизиты для печатной формы, скачивание резервной копии базы |

### Права доступа

- **Руководитель** — всё, включая финансы, зарплату, сотрудников и удаление.
- **Приёмщик / менеджер** — клиенты, заказ-наряды, склад, приём оплат. Финансы и зарплату не видит.
- **Мастер** — видит заказ-наряды, меняет статус (кроме «Выдан» и «Отменён»), пишет диагностику, видит **только свою** зарплату.

### Как считается зарплата

1. В прайсе у каждой услуги задан процент мастеру (например, «Ремонт форсунки CR» — 4 500 ₽, 40 %).
2. При добавлении работы в заказ-наряд выбирается мастер; цена и процент копируются из прайса (руководитель может поправить их в строке). Если потом поменять прайс, старые заказ-наряды не изменятся.
3. Когда заказ-наряд переводят в статус **«Готов»** или **«Выдан»**, его работы попадают в зарплату мастера с датой выполнения.
4. Выплата или аванс записывается в разделе «Зарплата» (или расходом с указанием сотрудника). «К выплате» = всё начисленное − все выплаты.

## Установка на Windows

1. Установите **Python 3.10 или новее** с сайта [python.org](https://www.python.org/downloads/). При установке **обязательно поставьте галочку «Add Python to PATH»**.
2. Скачайте программу: на GitHub нажмите **Code → Download ZIP** и распакуйте, например, в `C:\DieselService`.
3. Запустите **`start.bat`** двойным щелчком. В первый раз он сам установит нужные компоненты (нужен интернет, 1–2 минуты).
4. Откройте в браузере адрес, который покажет окно, — обычно **http://127.0.0.1:8000**.
5. При первом входе программа попросит создать учётную запись руководителя.

Окно `start.bat` должно оставаться открытым, пока программой пользуются. Чтобы программа запускалась сама, положите ярлык на `start.bat` в папку автозагрузки (`Win + R` → `shell:startup`).

На Linux / macOS вместо `start.bat` используйте `./start.sh`.

### Доступ с других компьютеров и телефонов в сервисе

Окно запуска показывает адрес вида `http://192.168.1.10:8000` — откройте его на любом устройстве в той же сети. Если не открывается, разрешите порт 8000 в брандмауэре Windows (при первом запуске Windows обычно спрашивает сама — нажмите «Разрешить доступ»).

Компьютеру с программой лучше закрепить постоянный IP-адрес в настройках роутера, чтобы адрес не менялся.

### Доступ из дома

**Не открывайте порт программы в интернет напрямую через роутер.** Безопасные варианты:

- **Tailscale (проще всего, бесплатно).** Установите [Tailscale](https://tailscale.com/download) на компьютер с программой и на свой телефон или домашний компьютер, войдите в одну учётную запись. После этого программа открывается из любого места по адресу `http://<имя-компьютера>:8000`, а для всех остальных она невидима.
- **Cloudflare Tunnel** — если нужен обычный адрес в интернете с HTTPS. В этом случае запускайте программу с переменной `DIESEL_HTTPS=1`, чтобы cookie входа передавались только по защищённому соединению.

В программе уже есть вход по паролю, ограничение числа попыток входа и защита форм, но доступ через VPN — дополнительный надёжный барьер.

## Резервные копии

Все данные хранятся в одном файле: `data\diesel_service.db`. Рядом лежит `data\secret_key` — ключ, без которого все пользователи будут разлогинены (данные при этом не теряются).

- Руководитель может в любой момент скачать копию: **Настройки → Скачать копию базы**. Это безопасно делать прямо во время работы.
- Делайте копию хотя бы раз в неделю и храните её **не на том же компьютере** (флешка, облако).
- Восстановление: закройте программу, переименуйте скачанный файл в `diesel_service.db` и положите его в папку `data` вместо старого.

## Параметры запуска

```
python run.py                      # порт 8000, доступно всей локальной сети
python run.py --port 8080          # другой порт
python run.py --host 127.0.0.1     # только с этого компьютера
```

Переменные окружения:

- `DIESEL_DATA_DIR` — папка для базы данных (по умолчанию `data` рядом с программой);
- `DIESEL_HTTPS=1` — если программа работает за HTTPS (Cloudflare Tunnel, обратный прокси).

## Для разработчика

Python 3.10+, Flask, SQLite, сервер Waitress. Внешних JS/CSS-библиотек нет: всё работает без интернета.

```
app/
  __init__.py      создание приложения, фильтры шаблонов
  schema.sql       схема базы данных
  db.py            работа с SQLite
  auth.py          вход, роли, CSRF-защита, ограничение попыток входа
  stock.py         все изменения складских остатков
  utils.py         справочники статусов и статей, форматирование
  views/           разделы: orders, clients, services, warehouse, finance, salary, employees, settings, dashboard
  templates/       HTML-шаблоны
  static/          style.css, app.js
run.py             запуск через Waitress
tests/             автотесты
```

Запуск тестов:

```
pip install -r requirements-dev.txt
python -m pytest
```
